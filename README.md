# Simulador del Globo y las Ondas Desfasadas (v1.0)
Simulación interactiva en Python y HTML5 Canvas del ciclo cósmico cerrado: expansión impulsada por presión de gas, red esponjosa de materia normal y materia oscura, esferas sin luz, implosión por agotamiento y rebote en el Punto Cero.
